# enjoy-club

엔조이 투자 관리자: https://won429.github.io/enjoy-club/

기존 Google 로그인으로 지수 설정과 멤버 토큰 지급을 관리합니다. 특정 앱 관리자 이메일이나 멤버 등록 여부로 운영자를 제한하지 않으며, 지급 서버에서는 서명된 Firebase Google 로그인과 이메일 인증을 확인합니다.

멤버 토큰 지급은 대상·서버 기준가 확인 후 별도 확인 창에서 실행합니다. 등록된 멤버에게 각각 2토큰을 한 번 지급하고, 지급 시 가격을 보유 기준금액에 더합니다. 포인트는 차감하지 않습니다. 고정 캠페인으로 중복 지급을 막고, 모든 대상의 보유량과 내역을 서버에서 함께 저장합니다. 응답을 받지 못한 경우 ‘지급 대상·결과 확인’으로 완료 여부를 조회하세요.

기능 배포나 로그인, 미리보기는 실제 지급을 실행하지 않습니다. 구매·판매 잠금은 유지됩니다. 서버 구현은 won429/enjoy-app의 cloudflare-worker/investment-grants.js에 있습니다.

검증: `node --test tests/grants.test.cjs`
